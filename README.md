☕ Project: BARISTO CAFE App

BARISTO CAFE is a Flutter-based mobile application designed to make ordering from cafes faster and more convenient for customers.

Many cafes today ask customers to scan a QR code and open a web link to place orders, which can sometimes cause delays or queues. This application provides a dedicated mobile platform where users can directly browse menu items and place their orders easily.

📱 Features

- Browse different cafe menu items
- Order beverages like Cappuccino, Latte, Frappe, Matcha and Espresso
- Explore snacks, desserts, and refreshing drinks like Mojito and Lemonade
- User-friendly light theme UI** for smooth navigation
- Simple and clean design focused on quick ordering experience

🛠 Built With
Flutter  Dart  Android Studio  DartPad (for learning and testing Dart concepts)**
